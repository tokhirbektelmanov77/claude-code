# Дизайн-система «Espresso / Leather»

Утверждённое направление: тёмная премиальная эстетика барбершопа. Тёмная тема — основная для всех
интерфейсов (клиентская запись, кабинеты барбера и владельца, админ-панель). Светлый вариант
«Leather Day» оставлен как опция (переключатель луна/солнце) для персонала в ярко освещённом зале;
выбор хранится только в браузере устройства.

## Статусы записей

Статус передаётся одновременно **цветом полосы, тоном фона, иконкой и текстом**: в календаре есть
легенда, в списках используется бейдж. Это нужно для читаемости и для людей с нарушением цветовосприятия.

| Статус | Цвет | Иконка |
| --- | --- | --- |
| CONFIRMED | песочный `#D5C4AE` | — |
| COMPLETED | шалфейный `#A7BD8E` | ✓ |
| NO_SHOW | кирпичный `#E08A72` | пользователь с крестом |
| CANCELLED | серый `#8E8D88`, зачёркнуто | — |
| Блокировка / отпуск | янтарный `#E0B26A` | подпись типа |

Нерабочее время в календаре заштриховано, рабочее залито ровным цветом, техперерыв после услуги отображается штриховкой под карточкой записи.

## Типографика

Manrope (кириллица и latin-ext для узбекской латиницы). Шрифт подключается через `next/font`: скачивается при сборке и раздаётся с нашего домена.
Крупные заголовки — класс `.bf-display` (800, межбуквенный −0.035em), надзаголовки — `.bf-eyebrow`.
Время и цены выводятся моноширинными цифрами (`tabular-nums`).

## Фотографии

`PhotoHero` выводит фото на всю ширину с затемнением (scrim) для читаемости текста.
Источник: `business.coverUrl` (задаётся в «Настройках»), иначе встроенный кадр из `apps/web/public/images`.
**Встроенные кадры временные**: это увеличенные фрагменты утверждённого макета (около 300 px в исходнике).
До запуска их нужно заменить лицензированными фотографиями шириной не меньше 1600 px (см. `public/images/README.md`).

## Принципы

- Никаких декоративных градиентов, свечения и неона. Единственный градиент — затемнение под текстом на фото.
- Одна главная кнопка на экран (песочная), остальные — контурные или тёмные.
- Мобильная навигация: нижняя панель вкладок в кабинете, закреплённая кнопка «Продолжить» в мастере записи.
- Мастер записи: время сначала выбирается, потом подтверждается кнопкой «Продолжить · 16:00». Карточка успешной записи предлагает «Мои записи» и «Добавить в календарь» (файл `.ics` формируется в браузере).
- Клиентская запись без регистрации: имя и телефон на шаге подтверждения, отметка «Оплата барберу на месте».
