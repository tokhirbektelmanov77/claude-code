# BARBERFLOW — памятка для работы с проектом

Онлайн-запись к барберам Узбекистана (MVP). Монорепо pnpm в этой папке; остальной репозиторий (`../`) —
чужие файлы, их не трогать. Подробности: `README.md`, `docs/*.md`. Отвечать владельцу — по-русски.

## Решения владельца продукта (не пересматривать без его запроса)

- **Нет Telegram-бота и SMS.** Клиенты записываются **без регистрации**: имя + телефон (`POST /public/bookings`),
  управляют записью по секретной ссылке `/a/<token>`; «Мои записи» — записи с этого устройства (`localStorage`).
  Последняя версия с ботом — коммит `7fa0416` (метка `telegram-bot-version` на GitHub не поставлена: сессии
  запрещено пушить метки; инструкция для владельца — в истории разговора/ROADMAP).
- **Оплаты визитов через сервис нет** — клиент платит барберу на месте. Есть только подписка барбершопов
  (SOLO 59 000 / TEAM 49 000 за мастера, мин. 3), платежи подтверждает админ вручную. Payme/Click — не делать без запроса.
- **Сотрудники**: телефон + пароль (scrypt). В команду — только по ссылке-приглашению. Забытый пароль —
  временный пароль от владельца (только для сотрудников, целиком принадлежащих его бизнесу) или от админа платформы.
  `PLATFORM_ADMIN` — только `pnpm admin:create`. Телефоны не подтверждаются → номер не даёт никаких прав.
- **Дизайн «Espresso / Leather»** (`docs/DESIGN.md`): тёмная тема по умолчанию, палитра #1A120E / #3A2418 /
  #6B4A2E / #A88462 / #D5C4AE / #4A4A46 / #F4EBDF, Manrope. Без золотых градиентов, неона, «светлого SaaS».
  Статусы записей: цвет полосы + фон + иконка + подпись.
- Все тексты — в словарях `packages/shared/src/i18n/{ru,uz}.ts` (оба языка сразу), никакой кириллицы в компонентах.

## Запуск (облачный контейнер часто перезапускается — всё останавливается)

```bash
service postgresql start                       # локальный PostgreSQL 16 (Docker в контейнере нет)
cd barberflow && pnpm install && pnpm build:packages
pnpm db:migrate && pnpm db:seed               # seed печатает демо-день и ссылку демо-клиента
(cd apps/api && pnpm build && RELAX_RATE_LIMITS=true node --env-file=../../.env dist/main.js &)   # :4000
(cd apps/web && npx next dev --port 3000 &)    # :3000; затем report_preview_port 3000 для предпросмотра
```

Демо (пароль `barberflow-demo`, только dev): админ `+998900000001`, владелец `…02`, барбер Азиз `…03`.
Демо-сценарий: `/b/aziz` → «Мужская стрижка» → демо-день (ближайший вторник ≥ 2 дней, `demoDay()`) → 16:00.

## Проверки перед коммитом

```bash
pnpm typecheck && pnpm lint
pnpm test              # unit 24 + API 42 + worker 3; БД barberflow_test
pnpm test:e2e          # 17 сценариев; API нужен с RELAX_RATE_LIMITS=true; Playwright 1.63 (Chromium, без WebKit)
```

Коммитить и пушить только в ветку `claude/vigilant-darwin-fv3iy2`. Перед правками схемы БД — новая миграция
(`prisma migrate diff …` + ручная правка SQL; `migrate dev` в этом окружении неинтерактивен).

## Известные ловушки

- `sed '/a/,/b/d'` без найденного конца диапазона удаляет файл до конца — так однажды обрезался README.
- `git push` в цикле с `| tail` скрывает ошибку; проверять код возврата самого `git push`.
- Heredoc со строками вида `$...` иногда блокируется проверкой безопасности — файлы писать через Write.
